# Part F data source

**Dataset:** Unemployment across industries — monthly count of unemployed persons
by industry, Jan 2000 – Feb 2010, 14 industries (the `series` column is the category),
122 months each.

**Original source:** U.S. Bureau of Labor Statistics, Current Population Survey
(unemployed persons by industry of last job), as redistributed in the open
`vega-datasets` repository.

**Downloaded from:**
https://raw.githubusercontent.com/vega/vega-datasets/main/data/unemployment-across-industries.json

**Downloaded on:** 2026-10-18 (sandbox clock read 2026-10-17 UTC when the file was fetched;
the same day in Lahore terms). File: `unemployment-across-industries.json`, 185,641 bytes.

**Note:** This is REAL data (unlike everything else in this folder, which is synthetic
course data for CDB601220). Citation: U.S. Bureau of Labor Statistics via
vega-datasets (https://github.com/vega/vega-datasets), accessed 2026-10-18.
